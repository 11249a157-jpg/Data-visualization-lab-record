# Experiment No. 4: Introduction to Tableau and Installation

## Aim
To study Tableau and install Tableau Public for creating interactive data visualizations.

## Algorithm
1. Start the experiment.
2. Open a web browser and visit the official Tableau Public website.
3. Download Tableau Public compatible with the operating system.
4. Run the downloaded installer and follow the installation wizard.
5. Complete the installation process.
6. Launch Tableau Public and verify that the Home screen appears.
7. Explore the basic components of the Tableau workspace, including Connect, Open, Worksheet, Dashboard, Story, Data Pane, Marks Card, and Filters.
8. Stop the experiment.

## Description
Tableau is a data visualization and business intelligence tool used to analyze data and present information through interactive charts, graphs, dashboards, and reports.

**Tableau Public** is a free platform that allows users to create visualizations and publish them online. It supports connecting to data sources, preparing data, building worksheets, and combining visualizations into interactive dashboards.

### Important Components of Tableau

- **Connect:** Connects Tableau to supported data sources such as Excel files, text files, and CSV files.
- **Open:** Opens existing Tableau workbooks and saved projects.
- **Worksheet:** Provides a workspace for creating individual charts and visualizations.
- **Dashboard:** Combines multiple worksheets into a single interactive view.
- **Story:** Presents a sequence of worksheets or dashboards to communicate insights.
- **Data Pane:** Displays the fields available in the connected dataset, including dimensions and measures.
- **Marks Card:** Controls visual properties such as color, size, label, detail, and shape.
- **Filters:** Restricts the data displayed in a visualization according to selected conditions.

## Procedure
1. Visit the official website: https://public.tableau.com/

3. Open the downloaded installation file.
4. Follow the on-screen instructions to install the application.
5. Launch Tableau Public after installation.
6. Confirm that the Home screen opens successfully.
7. Explore the available data connection options and workspace components.
